# validation/ — 완료는 내가 판정한다

검증을 실행할 때마다 날짜별 파일(`YYYY-MM-DD.md`)에 **실행한 명령, 결과, 판정**을 남깁니다.
기대 결과는 [정답.md](../정답.md)(손으로 먼저 작성), 규칙 번호는 [docs/spec.md](../docs/spec.md)를 따릅니다.

| 검증 | 명령 | 확인하는 것 |
| --- | --- | --- |
| 타입 검사 | `npm run typecheck` | 코드 오류 |
| 단위·통합 테스트 | `npm test` | R4~R18, R20 로직(25개) |
| 시연 흐름·반응형 | `npm run build` → `npm run e2e` | site/index.html을 file://로 열어 시연 1~11단계, 5개 폭 가로 넘침, 휴대폰 조작 |
| 실사용 | `npm run e2e:real` | 저장소 이전, PDF·DOCX·한글 파일명 읽기, 실패 형식 거절, 새로고침 유지, 작업 파일 저장·열기, 외부 요청 0건 |
| 수동 확인 | 정답.md 대조 | 사람의 기대와 실제 결과 비교 |

검증하지 못한 항목은 ‘미검증’으로 적고 완료로 표시하지 않습니다.
