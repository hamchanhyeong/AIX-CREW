1기업 요구사항과 수행팀 해석의 구분

기획 내용은 기업이 실제로 요구한 두 가지 결과물을 중심으로 정리합니다. 아래 표의 왼쪽은 과제 카드·신청서에 쓰인 내용이고, 오른쪽은 수행팀이 그 내용을 해석하거나 보완한 것입니다. 오른쪽 내용은 기관 확인 전까지 확정하지 않습니다.

기업이 명시한 내용 기업 요구수행팀 해석·보완 수행팀 제안확인 상태
재기지원 사업 운영규칙 1부 작성3개 내역에 공통으로 적용하는 기본 규정으로 가정(목적·정의·대상·선정·협약·사업비·사후관리·제재 등)확인 필요 공통 1부인지, 사업별로 나눌지
재기지원 사업 요령 1부 작성운영규칙에서 위임한 세부 절차·기준·서식을 담는 하위 규정으로 가정확인 필요 운영규칙과 요령의 범위 구분, 기관 서식
계획(안) 투입 시 수정사항 표기 기능 포함새 운영계획(안)을 넣으면 바뀐 조건과 연결된 조문을 찾아 신구대비표(현행/개정안/사유)로 표시확인 필요 무엇과 무엇을 비교하는지(6장)
재기지원 사업 3개 내역, 1,398억원, 2027년 1월 본격 운영, 12월 초 초안 필요2027년 정부 예산안 보도의 재도전 3개 사업과 금액 합계가 일치함(2장)확인 필요 3개 내역이 해당 3개 사업인지, 규정 적용 범위
사업 운영계획(안) 작성 완료, 참고 가능한 규정 보유(창진원·중진공 유사사업)운영계획(안)이 조문의 1차 입력이고, 유사사업 규정은 구조 참고용확인 필요 제공 시점·비기밀 범위
활용 데이터: 공개자료(중소기업창업지원법, 창업·재도전성공패키지 지침 등)법령·지침은 공개 원문을 근거로 쓰고, 기관 내부자료는 별도 보안 절차로 다룸(9장)확인 필요 내부자료의 외부 AI 전송 가능 여부
착수 2026-11-16, 4주, 크루 5명 내외이번 제출(11-14)은 착수 전 기획 단계로 구분(8장)—

기업이 요구하지 않았지만 수행팀이 추가로 제안하는 것

  • 수행팀 제안 조문마다 근거(법령·지침 조항 또는 운영계획 항목)를 붙이는 근거 매핑표
  • 수행팀 제안 초안 작성과 변경 반영을 돕는 웹 기반 작성 지원 도구(MVP). 과제 카드의 "수정사항 표기 기능"을 구현하는 수단이며, 결과물 범위에 도구 자체를 포함할지는 확인 필요

2배경: 정책 환경과 기관 현황

2.1 2027년 재도전 분야 예산안 참고·보도

2026년 9월 1일 발표된 중소벤처기업부 2027년 예산안 보도에 따르면, 재도전 분야 3개 사업에 합계 1,398억원이 편성되었습니다. 정부안이며 국회 심의 중이고, 확정은 12월로 예상됩니다.

이 표를 쓰는 범위

  • 세 사업의 금액 합계는 과제 카드의 "3개 내역, 1,398억원"과 같습니다. 그러나 이 세 사업이 이번 운영규칙·요령의 적용 대상으로 확정된 것은 아닙니다. 중진공이 직접 운영하는 범위, 사업명·구성은 확인 필요입니다.
  • 금액·규모는 국회 확정 전 정부안이므로 조문에 넣지 않습니다. 규정 초안에서는 【확인 필요】로 비워 두고, 확정된 운영계획(안)이 들어오면 반영합니다.
  • 기존 기획안에 있던 "지원 한도 1억 → 1.5억원", "위기기업 포함", "130곳·최대 2억원 바우처", "중진공 운영 예정"은 공식 자료로 확인하지 못해 본문에서 삭제했습니다. 기관 자료로 확인되면 다시 반영합니다.

3해결해야 할 과제와 조문 작성 예시 재검토

3.1 규정을 만들기 전에 풀어야 할 세 가지 수행팀 제안

과제내용해결 방향
① 계획(안)은 규정이 아니다개조식 운영계획(안)을 장·조·항·호의 조문으로 옮겨야 하고, 계획에 없는 절차 조항(이의신청·제재·비밀유지 등)이 필요한지 판단해야 합니다.근거 매핑 후 조문 작성. 계획에 없는 조항은 근거와 함께 【확인 필요】로 제안
② 계획(안)과 예산이 아직 바뀐다국회 예산 확정(12월)이 초안 전달 시기와 겹칩니다. 확정된 금액·규모를 빠르게 반영할 방법이 필요합니다.수정사항 표기 기능(6장)
③ 적용 대상과 준비 수준이 확정되지 않았다적용 대상 사업의 범위와 사업별 운영계획(안)의 완성도가 확인되지 않았습니다.공통 조항부터 작성하고, 사업별 내용은 확인 후 작성(5장)

3.2 조문 작성 예시 재검토 (기존 기획안 5쪽)

기존 기획안은 운영계획(안)의 개조식 선정 기준을 조문으로 옮긴 예시를 보여 주었습니다. 검토 결과 다음 두 가지 문제가 있어 수정했습니다.

운영계획(안) · 개조식 (기존 예시)

◦ 기업현장평가표 70점 이상

◦ 은행권 추천서 보유기업은 생략 가능

예시 출처: 기존 기획안에 인용된 「2026 혁신바우처 재기컨설팅 세부 운영계획(안)」. 이번 사업의 운영계획(안)이 아니며 원문 대조 필요.

요령(안) · 조문 (수정 예시)

제○조(선정기준)

① 공단은 기업현장평가 결과 70점 이상인 기업을 지원대상으로 선정한다.

② 제1항에도 불구하고 은행권 추천서를 보유한 기업은 기업현장평가를 생략할 수 있다. 이 경우 선정 기준은 【확인 필요】로 한다.

③ 【확인 필요】 평가위원의 제척·회피 기준(이해관계가 있는 평가위원 제외 등)의 근거 조항

발견한 문제수정 내용
논리적 공백: 현장평가를 생략한 기업은 "70점 이상" 기준을 적용할 수 없는데, 대신 무엇으로 선정하는지가 없음별도 선정 기준(서면평가, 추천서 요건 등)이 운영계획(안)이나 근거 규정에서 확인되지 않았으므로 제②항에 【확인 필요】를 표시. 수행팀이 임의 기준을 만들지 않음
근거 없는 보충 조항: 기존 예시 ③(이해관계 평가위원 제외)은 계획에 없는 내용을 채운 것인데 근거 조항이 제시되지 않음필요성은 제안하되 문안은 근거 확인 전까지 【확인 필요】로 표시

이 예시가 보여 주는 과제의 핵심: 계획(안)을 문장만 바꿔 옮기는 것이 아니라, 조문 사이의 공백을 찾아 기관에 확인을 요청하고, 확인된 근거가 있을 때만 조문을 채우는 것입니다.

4규정 체계와 법령 인용 검증

4.1 상위 규범의 관계 (검증 결과 반영)

기존 기획안은 "법률 → 시행령 → 통합관리지침(중기부 고시) → 운영규칙 → 요령" 순서로 그렸습니다. 확인 결과 통합관리지침은 법률이 아니라 중기부 「중소기업창업 지원사업 운영요령」 제38조에 근거한 하위 지침이어서, 그 사이에 운영요령이 있습니다. 이에 따라 체계도를 아래처럼 수정합니다.

법률 「중소기업창업 지원법」 확인
대통령령 「중소기업창업 지원법 시행령」 확인
중기부 행정규칙 「중소기업창업 지원사업 운영요령」 원문·고시 번호 확인 필요
지침 「중소기업창업 지원사업 통합관리지침」 (운영요령 제38조에 근거, 제14차 개정본 '25.12.23. 확인) 확인

명칭 혼동 주의

  • 중기부의 「중소기업창업 지원사업 운영요령」(상위 행정규칙)과 이번 결과물인 재기지원 사업 요령(기관 내부규정)은 서로 다른 문서입니다. 기획서와 초안에서는 결과물을 "재기지원 사업 요령(안)"으로 부르고, 상위 규범은 정식 명칭으로 씁니다.

  • 「재도전성공패키지 세부관리기준」은 다른 사업의 규정입니다. 구조(장 구성)를 참고하는 모델로만 쓰고, 이번 사업의 상위 규범으로 보지 않습니다.

4.2 법령 조항 인용 검증

기존 기획안에 인용된 조항을 공개자료로 대조했습니다. 국가법령정보센터 원문에 직접 접근하지 못한 경우가 있어, 확인 정도에 따라 구분합니다. 확인하지 못한 조항 번호는 본문에서 뺐습니다.

조항확인된 내용검증 상태
법 제42조재창업지원계획의 수립·시행(중기부장관)확인 현행 문언 대조 필요
법 제43조재창업자 등에 대한 성실경영 평가, 평가 기준 고시확인 현행 문언 대조 필요
법 제63조창업지원사업 참여제한(부정수급, 목적 외 사용, 환수금·제재부가금 미납 등)확인
시행령 제40조, 별표 4참여제한 기간·환수 범위의 사유별 기준확인
법 제10조, 제14조지원사업의 범위(통합관리지침 정의에서 인용), 창업지원사업 통합공고의 근거확인 2차 자료 기준
법 제2조재창업·재창업기업 정의가 있는 것으로 보이나 조항 위치 미확인확인 필요
법 제5·12·62·64조, 시행령 제2·4·7·41조 (기존 기획안 인용)인용 취지(지원 대상, 환수, 제재부가금, 비밀유지 등)와 조항이 맞는지 확인하지 못함본문에서 제외 원문 확인 후 재기재
재도전성공패키지 세부관리기준 제4·6·8·15·28·29조수행팀 확보 자료로 기존 기획안에 인용. 시행일(2026.4.23)과 조항 내용은 원문 재대조 필요참고 확인 필요

초안 작성 단계에서는 모든 조문 근거를 국가법령정보센터 현행 원문(시행일 명시)과 다시 대조하고, 대조하지 못한 조항 번호는 조문에 쓰지 않습니다.

5해결 방안 ① 운영규칙·요령 작성 방안

5.1 작성 절차 수행팀 제안

① 자료 수령운영계획(안), 유사사업 규정, 법령·지침 원문
② 근거 매핑규정 항목별로 계획 항목·법령 조항·참고 조문 연결
③ 목차 확정기관 운영계획(안) 확인 후 장·조 구성 확정
④ 조문 작성근거가 있는 내용만 조문화, 없으면 【확인 필요】
⑤ 사람 검수원문 대조, 용어 통일, 규칙·요령 간 일치

5.2 구성 가안 수행팀 제안 확인 필요

운영규칙과 요령의 구체적인 구성은 기관 내부 운영계획(안)을 확인한 뒤 확정합니다. 아래는 착수 전 검토를 위한 가안이며, 장·편의 수와 이름은 바뀔 수 있습니다.

적용 대상이 보도된 3개 사업으로 확정되는 경우를 가정한 작성 방식입니다. 확정 전에는 공통 조항부터 작성합니다.

5.4 다른 사업의 세부 기준을 그대로 쓰지 않는 원칙

기존 기획안은 재도전성공패키지 세부관리기준의 수치(위원회 구성·의결 정족수, 정부지원 비율·현금 부담 비율, 추가선정 기한)를 "바로 쓸 수 있는 기준"으로 제시했습니다. 다른 사업의 기준을 이번 사업에 그대로 적용하면 근거 없는 조문이 되므로 이 표현을 삭제했습니다.

  • 유사사업 규정은 조항 구성과 문안 형식의 참고로만 씁니다.
  • 수치·비율·기한은 이번 사업의 운영계획(안) 또는 상위 규범에서 확인된 값만 조문에 넣습니다.
  • 참고 규정의 수치를 제안할 때는 "참고: ○○사업 기준"이라고 출처를 밝히고 【확인 필요】로 표시해 기관이 채택 여부를 정하게 합니다.

6해결 방안 ② 수정사항 표기 기능

기업 요구 과제 카드에는 "계획(안) 투입 시 수정사항 표기 기능 포함"이라고만 되어 있습니다. 무엇과 무엇을 비교해 수정사항으로 표시할지는 명시되어 있지 않으므로 기업 확인이 필요합니다. 수행팀이 생각한 비교 대상 후보는 다음과 같습니다.

안비교 대상표시 결과MVP 반영
A이전 운영계획(안) ↔ 새 운영계획(안)바뀐 사업 조건(금액·규모 등)과 그 조건에 연결된 조문만 찾아 수정안과 신구대비표 작성기본 흐름으로 개발 중(7장)
B저장된 규정 초안 버전 ↔ 새 버전조문 단위 추가·삭제·수정 표시비교 기준 선택지로 개발 중

D상위 법령·지침 개정 전 ↔ 개정 후개정된 상위 조항을 근거로 쓰는 조문 표시미구현 계획 없음

기관에 확인할 내용

  • "수정사항"이 위 A~E 중 무엇인지(복수 가능), 그리고 비교 기준이 되는 "현행"이 무엇인지
  • 표시 형식: 신구대비표(현행 / 개정안 / 사유)로 충분한지, 기관 고유 양식이 있는지
  • 수정사항을 표시만 하면 되는지, 수정이 반영된 문서 파일까지 필요한지

예시 — A안의 출력 형태 (시연용 가상 값)

조항변경 전변경 제안변경 사유·근거반영 상태
지원 한도기업당 최대 1억원기업당 최대 1.5억원새 운영계획(안)의 지원 한도 변경반영

위 금액은 MVP 시연용 가상 자료이며 실제 사업 조건이 아닙니다. 기존 기획안의 "185개사 → 320개사" 예시는 보도 수치를 조문 예시로 쓴 것이어서 삭제했습니다.

설계 원칙 수행팀 제안

  • 문자열 일괄 치환이 아니라 조건 ↔ 조문 연결로만 반영합니다. 같은 숫자가 있어도 연결되지 않은 조문은 바꾸지 않습니다.
  • 수정안은 담당자가 조문별로 반영·보류를 결정하며, 자동 반영하지 않습니다.
  • 연결되지 않은 조문은 "자동 검토 범위 밖"으로 표시해 사람이 확인하게 합니다.

7이번 제출물: MVP 구현 현황

현황 확인 기준

MVP는 별도 세션에서 개발 중입니다. 프로젝트에 MVP_STATUS.md가 없어 최종 제출본의 구현 상태를 확정할 수 없습니다. 아래 표는 개발 브랜치의 README·기능 명세·검증 기록(2026-11-12, 최신 커밋 f0cb4f5)을 읽고 정리한 것입니다. 이 문서에서는 어떤 기능도 "구현 완료"로 표시하지 않으며, 제출 시점에 MVP 담당자가 최종 동작을 확인해야 합니다.

기능내용상태
자료 등록운영계획(안)·법령·지침·유사사업 규정·배경자료 구분 등록. TXT·텍스트 PDF·DOCX 읽기개발 중 · 확인 필요 검증 기록상 시연 통과. HWP·스캔 PDF는 지원하지 않음

문서 내보내기운영규칙·요령 초안, 신구대비표 DOCX, 근거 매핑표 CSV확인 필요 파일 생성은 기록됨. Word·한글에서 열기 미검증
상위 법령·지침 개정 자동 대조(6장 D안)—미구현
실제 기관 자료로 초안 작성—미수행 운영계획(안) 미수령
로그인·공동 편집·기관 PC 설치—범위 밖 단일 사용자 로컬 실행

이번에 제출하는 MVP는 가상 자료로 작성 흐름을 보여 주는 시연용입니다. 실제 사업 조건이나 법령 해석이 들어 있지 않으며, 산출 문서는 모두 검토용 초안입니다.

9위험 요소와 대응

9.1 기관 내부자료 보안과 외부 AI API 사용

운영계획(안)·유사사업 규정 등 기관 내부자료를 외부 AI API(클라우드 LLM)에 보내면, 자료가 기관 밖 서버로 전송됩니다. 제공업체의 보관·처리 정책과 기관 보안 규정에 따라 정보 유출 위험이 생길 수 있습니다. 수행팀 저장소(GitHub)나 개인 PC를 통한 유출 가능성도 있습니다.

위험대응
내부자료가 외부 AI API로 전송됨
  • 기관이 외부 AI 사용을 승인하기 전에는 공개자료(법령·지침·보도)만 AI에 보냄
  • 내부자료는 기본적으로 AI를 쓰지 않는 템플릿 방식으로 작성하고, 자료마다 "외부 전송 허용" 여부를 표시해 허용한 자료만 전송(MVP 설계 반영 여부 확인 필요)
  • 전송할 때도 전체 문서가 아니라 필요한 원문 조각만 보냄
  • 사용할 API의 데이터 보관·학습 활용 정책을 확인하고 기관 정보보호 담당과 사전 협의
저장소·PC를 통한 유출
  • 기관 내부자료와 개인정보(담당자 연락처 등)는 공개 저장소에 올리지 않음
  • 작업 데이터 폴더는 버전 관리에서 제외하고, 과제 종료 시 수행팀 PC의 내부자료 삭제
  • MVP는 인증이 없으므로 기관 자료가 들어간 상태로 외부에 배포하지 않음
API 키 노출키는 서버 환경변수로만 관리하고 저장소에 커밋하지 않음

9.2 그 밖의 위험

위험영향대응
적용 대상·구성 미확정목차와 조문 전체가 바뀜공통 조항부터 작성, 착수 시 범위 확정
예산·계획(안) 확정 지연금액·규모 조문 미확정【확인 필요】로 비워 두고 확정 시 변경 반영 기능으로 일괄 반영
AI 문안의 근거 오류·없는 조항 생성규정 신뢰도 하락모든 조문에 근거 표시, 법령 조항 번호는 원문에서 재확인, 근거 없으면 【확인 필요】, 사람 검수 필수
다른 사업 기준의 잘못된 적용근거 없는 수치가 조문에 들어감참고 규정 수치는 출처 표시 + 【확인 필요】, 기관이 채택 결정(5.4)
법령 원문 확인 지연조항 인용 오류국가법령정보센터 현행 원문을 시행일과 함께 보관, 미대조 조항은 쓰지 않음
참고 규정 원문 확보 지연사업별 편 작성 지연확보한 공개 법령으로 공통 조항부터 작성, 원문 수령 후 보완
제출 형식(HWP) 요구변환 작업 발생DOCX로 작성 후 한글에서 변환 가능 여부 착수 시 확인

10기대효과와 검증 방법

아래 효과는 기대하는 효과이며 아직 검증되지 않았습니다. 성능이나 시간 절감 수치는 측정 전이므로 제시하지 않고, 과제 수행 중 확인할 방법을 함께 적습니다.

기대효과설명검증 방법
검수 부담 완화조문마다 근거가 붙어 있어 담당자가 원문을 다시 찾는 수고를 줄일 수 있을 것으로 기대기관 검토 시 근거 표시가 검수에 도움이 되었는지 의견 수렴, 근거 미표시 조문 수 집계
변경 대응 지원계획(안)이 바뀌면 연결된 조문 후보를 찾아 신구대비표로 보여 줌확정 계획(안) 투입 시 수작업 대조 결과와 비교해 누락·오탐 확인
확인 필요 사항의 가시화근거가 없거나 미확정인 내용이 【확인 필요】로 모여 기관이 결정할 항목이 분명해짐【확인 필요】 목록을 기관과 함께 해소하며 건수 변화 확인
작성 시간시간 절감 효과는 아직 측정하지 않음시범 작성 시 단계별 소요 시간 기록(수치 목표는 정하지 않음)

기존 기획안의 "업로드부터 다운로드까지 30분 이내", "검수 시간 단축", "바로 결재에 올릴 수 있는 초안" 같은 단정적 표현은 삭제했습니다. 산출물은 모두 기관 검토가 필요한 초안입니다.
