# 재기지원 사업 규정 작성 지원 도구 — 사용자 설명서

대상: 중소벤처기업진흥공단 창업지원처 규정 작성 담당자 · 버전 1.0.0

> 이 도구가 만드는 모든 문서는 **검토용 초안**입니다. 기관 승인이나 법적 적합성을 보장하지 않으며,
> 조문은 법령 원문과 대조해 담당자가 확정해야 합니다.

## 1. 무엇을 하는 도구인가
운영계획(안)과 근거 자료(법령·지침·유사사업 규정)를 넣으면

- **재기지원 사업 운영규칙(안) 1부** — 3개 세부사업 공통, 8개 장
- **재기지원 사업 운영요령(안) 1부** — 공통편 + 재도전성공학교·재도전성공패키지·재도전응원프로젝트 편

의 초안을 조문 형식으로 만들고, 운영계획(안)이 바뀌면 **바뀐 조건과 연결된 조항만** 찾아 **신구대비표**로 보여 줍니다.

## 2. 설치와 실행
1. 받은 압축 파일을 PC의 원하는 위치에 풉니다(예: `문서\재기지원_규정작성도구`).
2. 폴더 안의 `index.html`을 더블클릭해 **Chrome 또는 Edge**로 엽니다.
3. 별도 설치, 인터넷 연결, 서버가 필요 없습니다. 태블릿·휴대폰 브라우저에서도 화면이 맞춰집니다.

> `index.html`과 `assets` 폴더는 항상 같은 폴더에 두세요. `index.html`만 따로 복사하면 열리지 않습니다.

## 3. 처음 사용할 때
- 첫 화면의 **연습용 샘플로 먼저 해 보기**를 누르면 가상 자료로 전체 흐름을 연습할 수 있습니다. 샘플은 실제 작업공간과 따로 저장되며, 모든 수치는 가상입니다.
- 실제 작업은 화면 위쪽 **작업공간: 실제 작업공간**에서 합니다.

## 4. 작업 순서
| 단계 | 메뉴 | 할 일 |
| --- | --- | --- |
| 1 | 자료 관리 | 운영계획(안)과 근거 자료를 등록합니다. |
| 2 | 사업 조건 확인 | 운영계획(안)에서 찾은 금액·기간·규모 등을 확인하고 확정합니다. 모르는 값은 비워 둡니다. ‘조건 확인 완료’를 누릅니다. |
| 3 | 규정 편집기 | ‘운영규칙·요령 초안 작성’을 누른 뒤 조항별로 고치고, 오른쪽 근거를 확인하고, ‘검토 완료’로 표시합니다. |
| 4 | 검토 목록 | 근거가 없거나 값이 맞지 않는 조항을 모아 봅니다. 누르면 해당 조항으로 이동합니다. |
| 5 | 계획 변경·신구대비표 | 새 운영계획(안)을 등록하거나 조건을 직접 바꾸면 연결된 조항에 수정안이 생깁니다. 반영·보류를 고르고 새 버전으로 저장합니다. |
| 6 | 내보내기·작업 파일 | 운영규칙·운영요령·신구대비표(Word), 근거 매핑표(CSV)를 내려받습니다. |

## 5. 자료 준비
**지원하는 형식**: 글자가 선택되는 PDF, DOCX, TXT, 본문 붙여넣기

**지원하지 않는 형식**: HWP, 스캔 이미지 PDF. 이런 파일은 한글에서 ‘다른 이름으로 저장 → PDF 또는 DOCX’로 저장하거나 본문을 복사해 붙여넣으세요.

- **법령·시행령**: 국가법령정보센터에서 PDF로 저장하거나 본문을 붙여넣습니다. ‘버전’ 칸에 시행일을 적어 두세요.
- **유사사업 규정**: ‘유사사업 규정’ 유형으로 등록합니다. 참고용이며 이번 사업의 현행 규정이나 의무 기준으로 쓰이지 않습니다.
- **보도자료 등**: ‘배경자료’로 등록합니다. 조항의 근거로 연결되지 않습니다.
- **원문이 아직 없는 자료**: ‘목록만 등록’하면 ‘원문 미등록’으로 표시되어 나중에 채울 대상이 보입니다.
- **운영계획(안)**: 사업 조건을 자동으로 찾으려면 사업명 제목 줄 아래에 ‘항목: 값’ 형식으로 적습니다.

```
2. 재도전성공패키지
- 지원 대상: 폐업 경험이 있는 재창업 예정자
- 지원 한도(기업당 최대): 1억원
- 선정 규모: 185개사 내외
- 지원 기간: 협약일부터 10개월 이내
- 선정 방식: 서류평가 후 발표평가
```

인식하는 항목은 사업명, 사업 목적, 추진 주체, 사업비 관리, 자산 취득 사전승인 기준(공통)과 지원 대상, 제외 대상, 지원 한도, 지원 기간, 선정 규모, 선정 방식(사업별)입니다. 값이 ‘미정’이면 빈 값으로 처리됩니다.

## 6. 화면의 표시
| 표시 | 뜻 |
| --- | --- |
| 【확인 필요: …】 | 근거 원문이나 사업 조건 값이 없어 확인이 필요한 부분. 내보낸 Word 파일에도 노란 표시로 남습니다. |
| 【미확정】 | 값은 있으나 아직 확정하지 않은 사업 조건 |
| 적용 근거 후보 | 법령·지침 원문에서 찾은 근거 후보. 적용 여부는 담당자가 확인 |
| 유사사업 참고 | 유사사업 규정. 참고용 |
| 운영계획 반영 | 운영계획(안) 조건이 조문에 들어간 근거 |
| 작성 제안·근거 확인 필요 | 연결된 근거 원문이 없는 문구 |
| 재검토 필요 | 검토 완료 후 조항이나 근거 원문이 바뀐 조항 |

## 7. 계획(안)이 바뀌었을 때
1. 바뀐 운영계획(안)을 자료 관리에 새로 등록합니다(예: 버전 ‘예산 확정본’).
2. 계획 변경·신구대비표에서 그 계획(안)을 고르면 바뀐 조건만 표시됩니다.
3. ‘연결 조항 찾기 · 수정안 생성’을 누르면 **바뀐 조건과 연결된 조항만** 수정안이 생깁니다. 같은 숫자가 들어 있어도 연결되지 않은 조항은 바꾸지 않으며, 그런 조항 수를 함께 알려 줍니다.
4. 각 수정안을 ‘반영’ 또는 ‘보류’로 정합니다. 담당자가 고친 문장은 유지되고 값만 바뀝니다.
5. ‘반영 결과를 새 버전으로 저장’을 누른 뒤 ‘신구대비표.docx’를 내려받습니다.

## 8. 작업 내용의 보관과 이동
- 작업 내용은 **이 PC의 이 브라우저 안**에 자동 저장되며, 인터넷으로 전송되지 않습니다.
- **다른 PC로 옮기거나 동료에게 넘길 때**: 왼쪽 메뉴 아래 **작업 파일 저장**으로 `.json` 파일을 받고, 다른 PC에서 **내보내기·작업 파일 → 작업 파일 열기**로 엽니다.
- 브라우저의 ‘인터넷 사용 기록·사이트 데이터 삭제’를 하면 저장된 작업도 지워집니다. 작업 파일을 정기적으로 저장하세요. 오래 저장하지 않으면 현황 화면에 알림이 표시됩니다.
- 사생활 보호(InPrivate·시크릿) 창에서는 창을 닫으면 작업이 사라집니다.
- 작업 파일과 내려받은 문서에는 기관 내부 자료가 들어 있을 수 있으니 공개된 곳에 올리지 마세요.

| 운영요령 초안.docx | 공통편·사업별 편 조문, 부록 근거 목록 |
| 신구대비표.docx | 문서·조항 / 변경 전 / 변경 제안 / 변경 사유 / 관련 계획·근거 / 반영 상태 |
| 근거 매핑표.csv | 조항별 근거(역할·자료·버전·위치·인용·원문 상태). 엑셀에서 바로 열림 |

Word 파일은 한글(HWP)에서도 열 수 있으며, 필요하면 한글에서 HWP로 저장해 제출합니다.

## 10. 자주 묻는 질문
- **AI가 조문을 써 주나요?** 이 버전은 AI를 사용하지 않습니다. 조문 틀(템플릿)에 확인된 사업 조건을 넣어 초안을 만들고, 근거는 등록한 원문에서 찾아 연결합니다. 자료가 외부로 나가지 않습니다.
- **법령 조문 번호가 왜 비어 있나요?** 원문이 등록되지 않은 법령의 조문 번호는 만들지 않고 【확인 필요】로 남깁니다. 법령 원문을 등록하면 근거 후보로 연결됩니다.
- **목차(장·편)를 바꿀 수 있나요?** 규정 편집기 목차에서 이름 바꾸기, 조항 추가·삭제·순서 변경이 됩니다. 조문 번호는 순서에 따라 자동으로 매겨집니다.
- **같은 PC에서 여러 사람이 쓰나요?** 한 브라우저에 실제 작업공간은 하나입니다. 사람마다 작업 파일을 저장·열기로 주고받으세요.

## 11. 지원 환경
Windows PC의 Chrome·Edge 최신 버전을 권장합니다. 태블릿·휴대폰 브라우저에서도 사용할 수 있습니다(화면 폭에 맞춰 메뉴·표 배치가 바뀜).
